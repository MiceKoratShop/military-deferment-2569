# ระบบลงทะเบียนผ่อนผันการเข้ารับราชการทหารกองประจำการ ปีการศึกษา 2569

ระบบเก็บข้อมูลนักศึกษาที่จะขอผ่อนผันการเข้ารับราชการทหารกองประจำการ (ทหารกองเกิน) อ้างอิงจากประกาศประชาสัมพันธ์

- รับเฉพาะนักศึกษาที่ **เกิดปี พ.ศ. 2549**
- **ผ่อนผันครั้งเดียว** — ผู้ที่เคยผ่อนผันแล้วในปีก่อนไม่ต้องลงทะเบียนซ้ำ (ระบบจะแจ้งและไม่ให้กรอก)
- เอกสาร 6 รายการ อย่างละ 4 ชุด (สด.35, สด.9, ทะเบียนบ้าน, บัตรประชาชน, เปลี่ยนชื่อ-สกุล*, เปลี่ยนภูมิลำเนาทหาร*)
- ส่งเอกสารที่ **ม.สมรักษ์** โดยตรง ภายใน **18 ธันวาคม 2569** — เลยกำหนดเสียค่าดำเนินการ 300 บาท
- สอบถาม 082-373-6964 (ม.เต่อ)

## ความสามารถ

| ส่วน | รายละเอียด |
|---|---|
| ลงทะเบียน | ฟอร์มข้อมูลส่วนตัว การศึกษา ภูมิลำเนาทหาร เช็กลิสต์เอกสาร ความยินยอม PDPA, ตรวจเลขบัตรประชาชน 13 หลัก (checksum), ตรวจปีเกิด 2549, กันลงทะเบียนซ้ำ, ออกเลขอ้างอิง `MD69-xxxx` |
| ตรวจสอบสถานะ | นักศึกษากรอกเลขบัตร + รหัสนักศึกษา เพื่อดูสถานะและหมายเหตุจากเจ้าหน้าที่ |
| ผู้ดูแลระบบ | เข้าด้วยรหัสผ่าน ดูรายชื่อ ค้นหา กรองสถานะ/ระดับชั้น เปลี่ยนสถานะ ใส่หมายเหตุ ส่งออก CSV (เปิดใน Excel ได้) |
| ฐานข้อมูล | Google Sheets (ชีต "ลงทะเบียน") ข้อมูลอยู่ใน Google Drive ของผู้ดูแล ไม่เปิดเผยสาธารณะ |

สถานะ: `รอส่งเอกสาร` → `ได้รับเอกสารแล้ว` / `เอกสารไม่ครบ` → `ส่งเรื่องผ่อนผันแล้ว`

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)

### 1. สร้างฐานข้อมูล + Apps Script
1. เข้า <https://sheets.new> สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `ผ่อนผันทหาร 2569`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก [`apps-script/Code.gs`](apps-script/Code.gs)
4. กด **+ → HTML** ตั้งชื่อไฟล์ว่า `index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาทั้งหมดจาก [`index.html`](index.html)
5. เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (บัญชี Google ของคุณ)
6. ตั้งรหัสผ่านผู้ดูแล: **การตั้งค่าโปรเจ็กต์ (⚙️) → คุณสมบัติสคริปต์ → แก้ `ADMIN_PASSWORD`**

### 2. เผยแพร่เป็นเว็บแอป
1. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
2. ดำเนินการในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
3. กดทำให้ใช้งานได้ คัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`) — เปิดลิงก์นี้ใช้งานได้ทันที

> แก้โค้ดภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** จึงจะมีผล

### 3A. ฝังใน Google Sites
1. เปิด Google Sites → **แทรก → ฝัง (Embed) → ตามURL** วาง URL `/exec`
2. ปรับขนาดกรอบให้สูงพอ (แนะนำเต็มหน้า) แล้วกด **เผยแพร่**

### 3B. ใช้ผ่าน GitHub Pages
1. แก้ `index.html` ใน repo นี้ บรรทัด `API_URL: ""` ใส่ URL `/exec` ที่ได้
2. Commit — หน้า GitHub Pages จะบันทึกข้อมูลลง Google Sheet เดียวกัน

## ความปลอดภัยของข้อมูล
- ข้อมูลส่วนบุคคล (เลขบัตรประชาชน ฯลฯ) อยู่ใน Google Sheet ส่วนตัวของผู้ดูแลเท่านั้น ไม่ได้อยู่บน GitHub
- นักศึกษาตรวจสถานะได้เฉพาะของตัวเอง (ต้องรู้ทั้งเลขบัตรและรหัสนักศึกษา)
- อย่าแชร์ Google Sheet แบบสาธารณะ และเปลี่ยนรหัสผ่านผู้ดูแลก่อนเปิดใช้จริง
